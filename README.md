# Mock Banking Application JavaScript

## Overview
This is a simple web page created with the functionality of the user being able to switch between 3 different bank accounts and deposit and withdraw money from the total of each account. The user can also press a button to display the current account balance after any deposits and withdrawals in the browser logs.<br>
The bank accounts are created using JavaScript Constructors.<br>
The code for this page was split into modules to demonstrate my proficiency with importing and exporting script files in JavaScript. This application has been hosted on AWS amplify to allow it to be easily used without running into CORS errors: https://main.d3a67s7jpya2xt.amplifyapp.com/<br>
A preview of what this project looks like when deployed can also be viewed on Vercel at this link: https://mock-banking-application.vercel.app/
